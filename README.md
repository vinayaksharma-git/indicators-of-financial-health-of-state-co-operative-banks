# Indicators of Financial Health of State Co-operative Banks

## 1. Description ✒️

This project delivers a comprehensive Power BI dashboard that analyzes the key financial health metrics of State Co-operative Banks across India. It tracks performance trajectories across multiple fiscal years, highlighting regional profit/loss distributions, loan recovery efficiencies, and non-performing assets (NPAs) to support data-driven decision-making in agricultural and rural banking sectors.

## 2. Data Source 🌐

National Data Analytical Platform (NDAP)



## 3. Business Objective 🏢

* Identify top-performing and loss-making State Co-operative Banks across different Indian states.


* Evaluate year-over-year profitability trends and loan recovery efficiency.


* Highlight regions with high Non-Performing Assets (NPAs) to aid policy interventions, risk mitigation, and financial restructuring.



💡 ***NOTE:*** *The visual analysis uses scaled metrics (e.g., billions in INR for aggregated profits/losses) and percentage ratios for standardized cross-state evaluations.*

## 4. Tools & Technologies 🛠️

* Excel
* Power BI

## 5. Key Insights & Solutions 📊

* **Profitability Leadership:** Maharashtra leads overall profits among states (~43bn total), followed by Andhra Pradesh (~14bn) and Tamil Nadu (~11bn).


* **Loss Identification:** Jammu & Kashmir (-2.5bn), Arunachal Pradesh (-1.3bn), and Manipur (-0.6bn) account for the highest cumulative losses.


* **Recovery Trends:** Top states consistently achieve 95%–100% recovery-to-demand ratios (e.g., Haryana, Punjab, Rajasthan, Karnataka), whereas regions like Arunachal Pradesh and Jharkhand lag significantly in loan recovery performance.


* **Year-wise Financial Growth:** Overall co-operative bank profitability peaked in recent years (2022–2023), showing strong recovery compared to earlier operational cycles.
